このページは、各Notebookを**実行したときに何が起こり、何が分かるか**を、結果の表つきでまとめたものです。**予習**にも**答え合わせ**にも使えます。

## このページの見方
- 数値は、各Notebookを実行したときの出力です。乱数のシードを固定しているので、同じ数値になります（環境で小数点以下は少しずれることがあります）。
- 特に断りがなければ、**世界（データ）を変えた複数回の平均**。`標準誤差`は平均のぶれで、**差が標準誤差の2倍より小さいときは、差があるとは言えません**。
- 指標は **MAE**（平均絶対誤差、kWh/日。小さいほど良い）。**リード L** は予報を出してから対象日までの日数（L=1 は前日の夜）。
- 03・04・05 のNotebookは、`src/run_phase3.py`（約15分）・`run_phase4.py`（約20分）・`run_phase5.py`（約10分）を**先に実行**して作る結果のCSVを読みます。
- 詳しい考察は [../MANUAL.md](../MANUAL.md)、最終レポートは [../REPORT.md](../REPORT.md)。

## 用語集
| 用語 | やさしい説明 |
|---|---|
| **持続予報** | L日前の値をそのまま予測にする。時系列予測の最も基本的な基準 |
| **平年値** | 同じ日付の、過去の平均 |
| **ラグ特徴量** | 過去の値を特徴量にしたもの |
| **リーク** | 予測時点で分からない情報（未来・答え）が入力に混ざること |
| **隠れた状態** | 直接は見えないが、過去の並びから推測できる要因（ここでは、雨で洗い流される「よごれ」） |
| **MLP** | 多層パーセプトロン。全結合のニューラルネット |
| **GRU／1D-CNN** | 系列を順に読む／窓の中のパターンを拾うニューラルネット |
| **早期終了・アンサンブル** | 検証の誤差が最小の時点で学習をやめる／初期値の違う複数のモデルを平均する |
| **分位点・pinball loss** | 「実測の90%がこれ以下」となる値／その学習用の損失 |
| **カバー率・CQR** | 区間に実測が入る割合／カバー率を合わせる校正 |

## 00 データと基準 — 日射予報だけで、どこまで当たるか
`発電量 = 0.85 × 真の日射量 × 温度の低下 × (1 − よごれ) × (1 + ノイズ3%)`。よごれは隠れた状態。

| 手法（L=1） | MAE |
|---|---|
| 持続予報（昨日の値） | 3.49 |
| 平年値 | 3.60 |
| 予報×0.85（学習なし） | 1.06 |
| 予報の直線回帰 | **0.875** |
| 上限1（予報が完璧） | 0.636 |
| 上限2（温度・よごれまで知っている） | 0.194 |

- 予報が最も効く。持続予報は、L≥2で平年値に負ける。上限1と上限2の差が、隠れた効果の大きさ。

## 01 古典的な機械学習
- **勾配ブースティングは、予報と季節だけで基準を7%上回る**（0.813）。ランダムフォレストは全特徴量で 0.785（約10%）。
- 過去の発電量・天気・気温・雨の降らない日数を足しても、**ほとんど良くならない**（予報の誤差に埋もれる）。
- リードが長いと改善は縮む（ランダムフォレストの相対改善 L=1: 10% → L=5: 2.8%）。
- **診断**: 予報を完璧にすると、過去の並びから隠れた状態を読める（HGB 0.284 → 0.218、上限0.194）。

## 02 ニューラルネット（MLP）
- 大きいネットは**過学習**（学習損失0.001、検証損失は悪化）。**小さく単純なほど安全**。
- 初期値だけでMAEが 0.852〜0.901 とぶれる。5つの平均で、ぶれが約1/3に。
- 全特徴量では木に負け、**予報・季節だけ**にするとL=3,5で最良（1.477・2.570）。ただしHGB（同特徴量）との差は小さい。

## 03 系列モデル — 生の時系列から、隠れた状態を読めるか
| 手法（L=1） | A 普通 | B 予報が完璧 | C 隠れた状態なし |
|---|---|---|---|
| HGB（手作り特徴量） | 0.790 | 0.214 | 0.218 |
| MLP（予報・季節だけ） | **0.770** | 0.267 | 0.209 |
| 窓MLP（窓を並べただけ） | 0.921 | 0.321 | 0.323 |
| **GRU（生の窓）** | 0.774 | **0.210** | 0.218 |

- GRUは、**手作りの特徴量なしで、よごれを自力で読めた**（予測の誤差とよごれの相関 0.07。直線回帰は 0.42）。
- 普通の世界では優位が出ず、**隠れた状態を消すと優位が消える**（対照実験）。窓MLPは全世界で過学習。

## 04 データ量とノイズ
- 普通の世界で、**1.5年**: HGB（全特徴量）0.895が直線回帰 0.867より悪い（過学習）。MLP（予報・季節だけ）0.836が最良。10年では MLP 0.761・GRU 0.769 が木 0.786 より良い。
- 予報が完璧な世界で、**GRUは1.5年でも崩れない**（0.276 対 HGB 0.293）。3年以上は手作り特徴量のHGBが同等以上。
- 「深層学習は大量のデータが必要」は、この小さなネットでは当てはまらない。
- ノイズが大きいほど、隠れた状態を読む価値は小さい（1%で0.099 → 10%で0.018）。

## 05 確率予測
| 手法（L=1） | 平均pinball損失 | 80%区間のカバー率 | 幅 |
|---|---|---|---|
| 線形＋一定幅 | 0.339 | 0.814 | 2.85 |
| HGB分位点（全特徴量） | 0.307 | **0.767**（自信過剰） | 2.44 |
| MLP分位点 | 0.300 | 0.809 | 2.55 |
| GRU分位点 | **0.295** | 0.803 | 2.47 |

- ニューラルネットは約1割良く、区間も正直。HGBは**CQR**（区間を0.117広げる）でカバー率が 0.761 → 0.812 に回復。
- 区間の幅はリードで約3倍（L=1→5）。MLPは晴れで狭く、曇りで広い（ただし曇りのカバー率は0.776）。

## 最終評価（REPORT.md）
新しい世界10個で1回だけ評価（MAE、世界A・10年・L=1）: 直線回帰 0.883、HGB 0.810、MLP 0.802、**GRU 0.791**。予報が完璧な世界B: **GRU 0.218**、HGB 0.224、予報・季節だけの手法 0.29〜0.30。確率予測のカバー率は MLP 0.791、GRU 0.794、HGB 0.754。詳しくは [../REPORT.md](../REPORT.md)。
